メロンパンShorts制作室

YouTubeチャンネル「メロンパン」を運営する個人開発者が、自分のチャンネル運用のためだけに作成・使用している非公開の自動化ツールです。 一般公開のサービスではなく、外部ユーザーへの提供やアカウント登録機能はありません。

提供者
個人開発者（YouTubeチャンネル「メロンパン」運営者本人）
用途
自分自身のYouTubeチャンネルへのShorts動画アップロード作業の自動化
利用者
開発者本人のみ（第三者への提供・公開なし）
連絡先
purosupihyouka@gmail.com

このツールでできること

日々のネタ探しから動画の構成・ナレーション音声・字幕・サムネイル作成までを行い、 開発者本人の確認・許可を経たうえで、YouTube Data API v3 を通じて開発者自身のチャンネルに動画をアップロードします。 アップロードは毎回、開発者本人の明示的な許可があった動画のみに限られます。

アクセスするGoogleアカウントの権限

  • youtube.upload 開発者自身のチャンネルへ動画をアップロードするために使用します。
  • youtube.readonly アップロード対象のチャンネル情報・動画一覧を確認するために使用します。

公開範囲について

本ツールはコードを一般公開しておらず、ダウンロードやサインアップの導線もありません。 Google APIの認証設定上、アプリ情報の登録先としてこのページを公開しています。 データの取り扱いについては、プライバシーポリシーをご覧ください。
