PRIVACY POLICY

メロンパンShorts制作室 プライバシーポリシー

最終更新日：2026年9月9日

本ツールは、YouTubeチャンネル「メロンパン」を運営する個人開発者が、自分自身のチャンネル運用を自動化するためだけに作成・使用している非公開の個人用ツールです。 Google API経由で取得する情報は、開発者自身のチャンネルへの動画アップロードという目的以外には一切使用せず、第三者への提供・販売・広告目的での利用は行いません。

01取得する情報

本ツールは、Googleアカウントの認証（OAuth）を通じて、以下のYouTube Data API v3のスコープへのアクセス許可を求めます。

スコープ内容
youtube.upload 開発者自身のチャンネルへ動画をアップロードする権限
youtube.readonly チャンネル情報・動画一覧などの閲覧権限

取得するのは開発者本人のYouTubeチャンネルに関する情報のみで、視聴者や第三者の個人情報を収集することはありません。

02情報の利用目的

  • 開発者本人が作成し、アップロードを許可した動画をYouTubeチャンネルに投稿するため
  • アップロード対象のチャンネルおよび動画の状態を確認するため

上記以外の目的（広告配信、第三者へのデータ提供、他サービスとの連携など）には一切使用しません。

03保存と保護

認証トークンおよびアップロード用の動画データは、開発者が管理する環境内にのみ保存され、外部への公開・共有は行いません。 本ツールの利用は開発者本人に限られ、他のユーザーがアクセスできる仕組みは提供していません。

04第三者提供

取得した情報を第三者に販売・貸与・提供することはありません。法令に基づく開示が求められる場合を除き、外部への共有は行いません。

05Google API Services User Data Policyの遵守

本ツールによるGoogleユーザーデータの取得・使用・共有は、制限付き利用の要件を含む Google API Services User Data Policy を遵守します。

06アクセス権限の取り消し

付与した権限は、いつでも Googleアカウントのセキュリティ設定 からご自身で取り消すことができます。
